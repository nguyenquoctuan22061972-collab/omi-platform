# Tech Spec

Bản thiết kế kỹ thuật cho từng module. **Bắt buộc trước khi tạo kiến trúc/code** (luật #1).

## Quy trình
1. Module có PRD duyệt → copy `_TEMPLATE.md` → `TechSpec-<mã module>.md`
2. Điền đủ → review → duyệt → mới code

## Danh sách Tech Spec
| Mã module | File | Trạng thái |
|---|---|---|
| _(chưa có)_ | | Chờ PRD duyệt |
