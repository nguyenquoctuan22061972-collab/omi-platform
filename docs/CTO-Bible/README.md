# CTO Bible

Quyết định kỹ thuật (ADR), chuẩn chung, bản đồ chức năng (chống trùng lặp — luật #4).

## Nội dung
- `standards.md` — coding standard, đặt tên, cấu trúc commit
- `adr/` — Architecture Decision Records (`ADR-000x.md`)
- `capability-map.md` — tra trước khi thêm chức năng mới

## Chuẩn commit (luật #5 — commit theo module)
```
<type>(<module>): <mô tả ngắn>
vd: docs(prd): thêm PRD-Finance
```
> _(điền dần khi có quyết định thực tế)_
