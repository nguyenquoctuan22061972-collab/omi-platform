# PRD-003: Automation n8n

> **Trạng thái:** DRAFT (chờ CEO/CTO duyệt). Phái sinh từ PRD-001 §9 + roadmap.
> **Scope hiện tại (B):** tài liệu + workflow JSON **importable**, credential ở dạng
> placeholder, **node cần secret để `disabled`**. Sẵn sàng chạy khi gắn
> `N8N_BASE_URL` + `CRM_BASE` + credentials.

## 1. Tên Module
Automation n8n

## 2. Mục tiêu
Tự động hoá luồng CRM đa kênh bằng n8n: tiếp nhận lead, hợp nhất & gắn tag, định
tuyến Sales, đồng bộ KPI — hiện thực 3 workflow WF001/WF002/WF050 dạng file JSON
import được vào n8n, không phụ thuộc thao tác thủ công.

## 3. Người dùng
- Admin (cấu hình n8n, credential, biến môi trường).
- Sales / CSKH (nhận lead & hội thoại được định tuyến).
- CEO (xem báo cáo KPI định kỳ).

## 4. Đầu vào (6 kênh — PRD-001 §4)
Facebook Messenger · Zalo OA · Telegram · Email · Form Landing Page · API Webhook.
Chuẩn hoá về payload: `{ name, phone, email, channel, message }`.

## 5. Đầu ra
- WF001 → contact hợp nhất + conversation (qua CRM Core API).
- WF002 → contact được auto-tag + định tuyến Sales/CSKH.
- WF050 → báo cáo KPI định kỳ.

## 6. API / Tích hợp (PRD-001 §6)
`POST {CRM_BASE}/contacts` · `POST {CRM_BASE}/messages` · `GET {CRM_BASE}/conversations`
· `GET {CRM_BASE}/dashboard/kpi` *(gap — xem §11)*. Base qua env `CRM_BASE`.

## 7. Database
Không sở hữu DB riêng. Trạng thái do CRM Core (PRD-001 §7) quản lý; n8n chỉ orchestrate.
Log thực thi lưu trong n8n (execution log).

## 8. UI
Không có UI riêng. Cấu hình qua n8n Editor; giám sát qua n8n Executions.

## 9. Workflow (map PRD-001 §9)
| Mã | Tên | Trigger | Map §9 |
|---|---|---|---|
| WF001 | Lead Ingestion | Webhook `crm/lead` | 9.1 + 9.2 |
| WF002 | AI Auto-Tag & Sales Routing | Webhook `crm/new-conversation` | 9.3 + 9.4 |
| WF050 | Dashboard KPI Sync | Schedule (cron) | 9.5 |

Luồng tổng: Lead → normalize → CRM merge → tag → route Sales → KPI sync.

## 10. Test Case (acceptance — scope B, tĩnh)
- TC1: 3 file JSON hợp lệ, import được vào n8n.
- TC2: mỗi workflow có ≥1 trigger + ≥1 HTTP node tới CRM.
- TC3: connection trỏ node tồn tại (không mồ côi).
- TC4: URL HTTP dùng `{{$env.CRM_BASE}}` — không hardcode host.
- TC5: không có secret literal trong JSON.
- TC6: mọi node yêu cầu credential đều `disabled` (chờ gắn secret).
- TC7: có `.env.example` liệt kê mọi biến cần thiết.

## 11. Risk & Gap
| # | Rủi ro | Giảm thiểu |
|---|---|---|
| R1 | Mất webhook | Retry + idempotency key (runbook) |
| R2 | Rate limit kênh | Backoff luỹ thừa (runbook §retry) |
| R3 | Secret lộ | Chỉ dùng credential n8n + env; JSON không chứa secret |
| R4 | Sai định tuyến | Switch có fallback; audit qua CRM |
| **Gap** | CRM Core **chưa có** `GET /dashboard/kpi` | Cần CR bổ sung endpoint trước khi bật WF050 |

## 12. Điều kiện "Go-live" (ngoài scope B)
Gắn `N8N_BASE_URL`, `CRM_BASE`, credential mỗi kênh + kênh notify → bật node
`disabled` → deploy. Bổ sung KPI endpoint cho CRM Core.
