# PRD-003: Automation n8n (DRAFT)

> ⚠️ **DRAFT — chờ CEO/CTO duyệt.** Nội dung phái sinh từ roadmap + PRD-001 §9
> (workflow CRM). Không mở rộng phạm vi ngoài các bước automation đã nêu ở PRD-001.
> Scope phiên này (phương án B): **tài liệu + workflow JSON importable, CHƯA nối
> credential/CHƯA deploy** — anh tự gắn credential trong n8n.

## 1. Tên Module
Automation n8n

## 2. Mục tiêu
Tự động hoá luồng CRM đa kênh bằng n8n: ingest lead, auto-tag & routing, đồng bộ
KPI — hiện thực 3 workflow WF001/WF002/WF050 dưới dạng file JSON import được vào n8n.

## 3. Người dùng
Vận hành (Sales/CSKH), Admin cấu hình n8n.

## 4. Đầu vào (kênh — như PRD-001 §4)
Facebook Messenger · Zalo OA · Telegram · Email · Form Landing Page · API Webhook.

## 5. Đầu ra
- WF001: contact hợp nhất + conversation (gọi CRM Core API).
- WF002: contact được auto-tag + định tuyến Sales.
- WF050: KPI được đồng bộ/báo cáo định kỳ.

## 6. Workflows
| Mã | Tên | Map PRD-001 §9 |
|---|---|---|
| WF001 | Lead Ingestion | 9.1 Lead vào + 9.2 Merge |
| WF002 | AI Auto-Tag & Sales Routing | 9.3 Tag + 9.4 Sales |
| WF050 | Dashboard KPI Sync | 9.5 Dashboard cập nhật |

## 7. Tích hợp CRM Core (PRD-001 §6)
Dùng `POST /contacts`, `POST /messages`, `GET /conversations`. Base URL qua biến môi
trường n8n `CRM_BASE`.

## 8. Cấu hình (do người dùng cung cấp khi deploy — ngoài scope B)
- `CRM_BASE` (URL CRM Core).
- Credential từng kênh (FB/Zalo/Telegram/Email) — gắn trong n8n UI.
- (Nếu bật WF050 KPI) endpoint KPI của CRM Core — xem "Phụ thuộc" bên dưới.

## 9. QA (scope B — không cần n8n chạy thật)
- JSON hợp lệ, import được vào n8n.
- Mỗi workflow có trigger + node HTTP tới CRM API.
- Connection hợp lệ (node đích tồn tại).
- URL HTTP tham số hoá qua `{{$env.CRM_BASE}}` (không hardcode/secret).

## 10. Risk
- Mất webhook → cần idempotency (mở rộng CRM ingestion).
- Rate limit kênh → n8n retry/backoff.
- Secret lộ → chỉ lưu credential trong n8n, không commit.

## 11. Phụ thuộc / Gap đã biết
- **KPI endpoint chưa có ở CRM Core** (PRD-001 §6 chỉ có 5 endpoint; `dashboard.kpi`
  là hàm module, chưa expose HTTP). WF050 tạm gọi `{{$env.CRM_BASE}}/dashboard/kpi`
  → cần một PRD/CR bổ sung endpoint này cho CRM Core trước khi bật WF050 thật.
