# PRD-005: Production Deployment

> Chỉ **bổ sung phần deployment**; không đổi PRD-001..004. Giữ naming/ADR/capability-map.

## 1. Tên Module
Production Deployment

## 2. Mục tiêu
Biến OMI Platform (CRM Core, Auth & RBAC, Dashboard, Automation n8n) thành bản
**production-ready**: container hoá, reverse proxy + SSL, CI/CD, secrets, backup,
monitoring, rollback, security hardening.

## 3. Người dùng
DevOps/Admin (vận hành), CTO (duyệt), toàn hệ thống (thụ hưởng).

## 4. Phạm vi (in-scope)
- Docker Compose production cho các service.
- Nginx reverse proxy + SSL (Let's Encrypt).
- CI/CD GitHub Actions (build, test, deploy).
- Secrets qua `.env` (chỉ có `.env.example` trong repo).
- Backup/Restore, Healthcheck, Monitoring, Logging, Alerting.
- Rollback strategy, Runbook, Disaster Recovery.
- Security hardening: RBAC, rate limit, CORS, CSP, security headers.

## 5. Ngoài phạm vi
- Không sửa business logic PRD-001..004 (chỉ đóng gói/vận hành).
- Không cấp secret thật trong repo (chỉ mẫu).

## 6. Kiến trúc triển khai
```
Internet ──443/80──> Nginx (SSL, rate limit, CORS, CSP, headers)
   ├── /            → dashboard (static)
   ├── /api/crm/    → crm-core:8080
   └── /api/auth/   → auth-rbac:8081
(n8n tách riêng, dùng CRM qua mạng nội bộ)
```

## 7. Cấu hình
`deploy/.env.example`: domain, email Let's Encrypt, AUTH_SECRET, ports, backup path…
Không commit `.env` thật.

## 8. Database / State
CRM Core & Auth dùng SQLite file trên volume bền (`./data`). Backup định kỳ volume.

## 9. Workflow triển khai
1. Set `.env` từ mẫu. 2. `docker compose -f deploy/docker-compose.prod.yml up -d`.
3. Nginx xin/nạp SSL. 4. Healthcheck xanh. 5. CI/CD tự build+test; deploy thủ công/dispatch.

## 10. QA (TC1-TC15 — acceptance, xem checklist)
Compose hợp lệ · Dockerfile mỗi service · nginx SSL+proxy · rate limit · CORS · CSP +
security headers · CI test job · deploy job · .env.example không secret · backup +
restore script · healthcheck · rollback doc · runbook · DR · security hardening doc.

## 11. Risk
| # | Rủi ro | Giảm thiểu |
|---|---|---|
| R1 | Lộ secret | `.env` gitignored; chỉ `.env.example` |
| R2 | SSL hết hạn | certbot auto-renew + alert |
| R3 | Mất dữ liệu | backup định kỳ + restore test |
| R4 | Deploy hỏng | healthcheck + rollback re-deploy image trước |
| R5 | Tấn công | rate limit + CSP + security headers + RBAC |

## 12. Acceptance
Tất cả TC1-TC15 PASS; CI xanh; checklist production đủ; không đổi PRD-001..004.
