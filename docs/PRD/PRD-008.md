# PRD-008: Runtime Integration & Observability (Giai đoạn 8)

> **Additive only.** Không đổi PRD-001→007, ADR, capability-map, naming, business logic.
> Đưa hệ thống từ code-ready → runtime-ready: observability, giám sát, audit, vận hành.

## 1. Mục tiêu
Tăng khả năng quan sát & vận hành sau khi gắn credential.

## 2. Phạm vi (8 module additive)
| Module | Vị trí | Nội dung |
|---|---|---|
| A Runtime Health | `apps/runtime-health/` | /health, deps, uptime, version, build, ready, live |
| B Structured Logging | `libs/logging/` | JSON log, request/correlation id, level, audit event, rotation |
| C Audit Trail | `libs/audit/` | deploy/login/role_change/workflow_activation/adapter_enable/rollback; redact secret |
| D Metrics Export | `libs/metrics/` | workflow_count, queue_size, adapter_status, dashboard_latency, health_summary (mock provider) |
| E Alert Policy | `docs/Operations/alert-policy.md` | P1-P4, escalation, owner, recovery, notification matrix |
| F Backup Verification | `deploy/backup/` | verify, checksum, restore-verify (dry-run), retention |
| G n8n Runtime Validation | `workflows/runtime/` | webhook/credential/disabled-node/activation report |
| H CEO Live Dashboard | `docs/Operations/CEO-Live-Dashboard.md` | revenue placeholder, health widgets, KPI mapping |

## 3. Ràng buộc
- Không thay endpoint cũ (Runtime Health là service + endpoint MỚI).
- Không sửa logger cũ (logging riêng, `propagate=False`).
- Không gọi Prometheus/API thật (mock/abstraction, dry-run).
- Không ghi secret vào audit/log (redact).
- Không sửa workflow business (chỉ đọc/validate).
- Không sửa Dashboard KPI (CEO-Live-Dashboard chỉ là spec).

## 4. QA
Validator + regression + runtime validator + backup dry-run + webhook validator; CI xanh.

## 5. Capabilities bổ sung (ghi tại đây — KHÔNG sửa capability-map theo nguyên tắc)
runtime-health, structured-logging, audit-trail, metrics-export (mock), n8n-runtime-validate.

## 6. Chờ credential/VPS để bật production
Metrics/health "live" cần service chạy (VPS); audit/log tập trung cần sink thật;
webhook validation thật cần n8n chạy; adapter thật cần credential.
