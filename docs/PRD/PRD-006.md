# PRD-006: Production Operations Layer (Giai đoạn 6.1)

> **Additive only.** Không đổi PRD-001→005, ADR, capability-map, naming, business logic.
> Chỉ thêm module còn thiếu để chuẩn bị go-live thật (chờ credential).

## 1. Tên Module
Production Operations Layer

## 2. Mục tiêu
Hoàn thiện Operations Layer + Contacts/Inbox/Pipeline skeleton + Adapter architecture
để sẵn sàng kích hoạt automation thật sau khi gắn credentials.

## 3. Phạm vi (6 module additive)
| Module | Vị trí | Nội dung |
|---|---|---|
| A Contacts Domain | `apps/dashboard/contacts/` | list, detail, search, filter, pagination + mock integration |
| B Inbox Domain | `apps/dashboard/inbox/` | unified inbox + 4 channel placeholder qua adapter |
| C Pipeline | `apps/dashboard/pipeline/` | Kanban, stages, deal detail, activity timeline, mock state |
| D Adapter Architecture | `libs/integrations/` | adapter chuẩn 6 provider, interface thống nhất, env-based |
| E Operations Dashboard | `apps/dashboard/operations/` | container/workflow/backup/CI/deploy/alert (mock) |
| F Runbook Expansion | `docs/Operations/*` | incident, rollback tree, cred rotation, DR drill, maintenance |

## 4. Ràng buộc
- Không đổi API hiện có (CRM Core PRD-001 §6 + CR-001).
- Không hardcode credential; đọc từ env; **không gọi API thật**.
- Không sửa Dashboard KPI (PRD-004) — Operations là trang standalone.
- Standalone (mỗi domain có index.html riêng) → không sửa router/app.js của PRD-004.

## 5. Đầu ra
UI skeleton dùng mock data; adapter layer sẵn interface; runbook mở rộng. Sẵn sàng
"chỉ cần gắn credential" để nối API thật ở phase sau.

## 6. QA (acceptance)
Validator per module PASS · toàn bộ test-suite xanh · CI không đỏ · không secret literal.

## 7. Capabilities bổ sung (ghi tại đây — KHÔNG sửa capability-map.md theo lệnh)
contacts-ui, inbox-ui, pipeline-ui, operations-ui (mock) · integration-adapters (6 provider, dry-run).

## 8. Risk
- Nhầm mock ↔ thật → adapter luôn dry-run tới khi có credential + cờ bật.
- Lộ secret → env-only, validator chặn secret literal.

## 9. Chờ credential để go-live
Adapter (D) + Inbox channel (B) + WF n8n (PRD-003) chỉ hoạt động thật khi gắn
credential env; hiện dry-run/mock.
