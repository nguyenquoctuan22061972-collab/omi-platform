# PRD-001: OMI Platform CRM Core

## 1. Tên Module
CRM Core

## 2. Mục tiêu
Xây dựng lõi CRM đa kênh để quản lý khách hàng, hội thoại và pipeline bán hàng.

## 3. Người dùng
- CEO
- Sales
- CSKH
- Admin

## 4. Đầu vào
- Facebook Messenger
- Zalo OA
- Telegram
- Email
- Form Landing Page
- API Webhook

## 5. Đầu ra
- Hồ sơ khách hàng hợp nhất.
- Timeline hội thoại.
- Pipeline bán hàng.
- Dashboard KPI.

## 6. API
- POST /contacts
- GET /contacts/{id}
- POST /messages
- GET /conversations
- POST /pipeline/update

## 7. Database
**Contacts:** id, name, phone, email, source, tags, created_at
**Conversations:** id, contact_id, channel, message, timestamp
**Pipeline:** lead, contacted, qualified, proposal, won, lost

## 8. UI
- Dashboard
- Contact List
- Conversation Inbox
- Pipeline Kanban
- Contact Detail

## 9. Workflow
1. Lead vào từ nhiều kênh.
2. Merge theo số điện thoại/email.
3. AI gắn tag.
4. Sales xử lý.
5. Dashboard cập nhật.

## 10. Test Case
- Trùng số điện thoại phải merge.
- Tin nhắn đúng contact.
- Pipeline cập nhật.
- KPI thay đổi theo thời gian thực.

## 11. Risk
- Trùng dữ liệu.
- Giới hạn API.
- Mất webhook.
- Phân quyền sai.
